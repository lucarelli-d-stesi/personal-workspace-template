# Distilled Knowledge (`knowledge/`)

This directory stores long-term, curated knowledge, reusable patterns, and architectural lessons harvested from day-to-day work.

## Size Budget & Discipline

- Files aim to remain under **400 lines**.
- When files grow larger, they must open with an `## Index` section or be split/compacted following the knowledge garbage collection routine (`knowledge/playbooks/knowledge-gc.md`).
- This knowledge is indexed automatically by the local semantic vector engine (`zg`).
