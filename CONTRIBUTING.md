# Contributing to Personal Workspace (POS)

Thank you for your interest in the **Personal Workspace** framework!

## Repository Nature: Personal Operational Framework

This repository is maintained as an individual **Personal Operating System (POS)** and cognitive framework. Because it is tailored to personal workflows, cognitive models, and individual operating principles:

- **We do not accept Pull Requests.**
- **We do not accept external code or feature contributions.**

Any Pull Requests opened against this repository will be automatically closed.

---

## How You Can Use and Adapt This System

You are warmly encouraged to adopt, explore, and tailor this framework for your own personal, academic, or professional life under the terms of the [MIT License](LICENSE):

1. **Use this repository as a template**:
   - Click the green **"Use this template"** button at the top of the GitHub repository page to create a brand-new, unlinked repository in your own GitHub account.
   - Alternatively, clone this repository directly to your local machine:
     ```bash
     git clone https://github.com/danielelucarelli1980/personal-workspace.git ~/personal-workspace
     ```
2. **Deploy your personal instance**:
   - Run the automated setup:
     ```bash
     cd ~/personal-workspace
     bash setup/bootstrap.sh
     ```
   - Follow the instructions to attach or initialize your own private instance repository where your life areas, private notes, and custom skills will live.
3. **Customize freely**:
   - Tailor the generic methodology skills (`.agents/skills/`), conventions, and playbooks to suit your own needs.
