# Reference — grows from use

This folder starts empty by design. Reference files are born from the
harvesting loop: lessons staged in the instance `inbox/` get consolidated
here (framework-worthy, domain-agnostic patterns) or into the instance's own
`knowledge/` (personal specifics) at weekly review.

Rules:
- One topic per file, kebab-case (`finance.md`, `meal-planning.md`).
- Every new file gets a routing row in `knowledge/INDEX.md`.
- Respect the size budget (`kernel/conventions.md`); compact with
  `playbooks/knowledge-gc.md` when over it.
- No personal data here — this repo is public. Personal specifics belong in
  the instance's `knowledge/`.
